The Friday Ledger is a newspaper-style Black Friday deal finder holding 37 deals across Amazon, Best Buy, Walmart, Target and Costco — every price read and checked on 27 November 2026, each deal carrying its store link, sale price, usual price, discount, check time and an honest verdict (Real deal, Good cut, or Thin — check twice), with live search and filters by category, store and discount, plus a detail page for every deal that explains in plain words why it earned its verdict.

## Run it

```sh
node main.ts
```
